# 使用说明

## 使用步骤

1. 运行代理软件，找到它提供的 HTTP 或 mixed 监听地址和端口。
2. 打开本工具，选择 Antigravity 主程序，填写代理地址和端口。
3. 可点击“测试连接”；该操作不提交账号信息。
4. 保存工作并完全退出已运行的 Antigravity，再点击“保存并启动”。
5. 成功后启动器自动退出；以后每次从本工具打开 Antigravity，保存过的设置会自动填入。

使用期间保持代理软件运行。浏览器登录仍需要可用的网络连接，例如系统代理。

## 修改设置

直接在窗口中修改程序位置、地址或端口。

- “测试连接”：检查代理端口和 Google 登录接口连通性。
- “保存设置”：只保存，供下次使用。
- “保存并启动”：保存设置并启动 Antigravity；成功后自动关闭。

更换代理软件但地址和端口不变时，不需要修改。换电脑或换 Windows 用户，需要重新填写。

## 配置保存位置

`%LOCALAPPDATA%\AntigravityProxyLauncher\settings.json`

exe 旁边不新建配置文件；同一 Windows 用户下移动 exe 后仍可读取原配置。

## 从 v1.3.0 回到简单模式

直接打开新版 exe，保留原有 settings.json 即可继续使用配置。

可以删除 v1.3.0 生成的“Antigravity（代理）”桌面图标和“Antigravity 代理设置”开始菜单入口。原先保存在 AppData 的旧启动组件不会因下载新版自动更新，日常请直接使用新版工具。

## 常见情况

代理未运行或端口错误时，窗口会显示原因；请启动代理或修改端口后重试。

提示 Antigravity 已运行时，请保存工作并完全退出，然后再用本工具启动，避免旧进程沿用原有网络环境。

连接测试通过但仍无法登录时，请保留软件的具体错误。连通性测试不代表账号资格或全部 AI 功能可用。

## 移除

关闭工具，删除下载的 exe 即可。如需同时清除配置，再删除 `%LOCALAPPDATA%\AntigravityProxyLauncher` 文件夹。这不会删除 Antigravity 本体。
