# 使用说明

## 第一次设置

1. 运行代理软件，找到它提供的 **HTTP 或 mixed 监听端口**。
2. 打开本工具，确认 Antigravity 程序位置，填写代理地址和端口。
3. 可点击“测试连接”；该操作不提交任何账号信息。
4. 点击“配置启动图标”，出现完成提示后关闭窗口。
5. 完全退出原本运行的 Antigravity，然后双击桌面“Antigravity（代理）”。

成功时不显示设置窗口，启动组件会立即退出。只有代理软件需要在使用期间继续运行。

原有的官方图标仍按原方式启动，不会自动获得本工具的代理设置。日常请使用新增的代理图标。

## 修改代理或程序位置

在 Windows 开始菜单搜索“Antigravity 代理设置”，或再次打开下载的工具。

修改后点击“保存设置”。已生成的启动图标会在下次启动时读取新设置，不需要重建图标。

更换代理软件但地址和端口不变时，不需要修改。换电脑或换 Windows 用户，需要重新配置。

## 按钮

| 按钮 | 用途 |
| --- | --- |
| 测试连接 | 检查代理端口和 Google 登录接口连通性 |
| 保存设置 | 保存当前配置，供下次静默启动使用 |
| 启动一次 | 保存并立即启动，成功后关闭窗口，不创建图标 |
| 配置启动图标 | 保存配置，部署启动组件，并创建或更新桌面启动入口和开始菜单设置入口 |

## 保存位置

- 启动组件：`%LOCALAPPDATA%\AntigravityProxyLauncher\Antigravity-Proxy-Launcher.exe`
- 设置：`%LOCALAPPDATA%\AntigravityProxyLauncher\settings.json`
- 桌面：`Antigravity（代理）.lnk`
- 当前用户开始菜单：`Antigravity 代理设置.lnk`

最初下载的 exe 旁边不会新建配置文件；配置完成后移动该下载文件不会影响快捷方式。

升级时打开新版下载文件，点击“配置启动图标”更新组件。更新前退出其他已打开的代理设置窗口。

## 常见情况

**代理软件没启动或端口填错**：静默启动会回到设置窗口，显示原因。启动代理或修改端口后重试。

**网页能登录，软件仍报错**：确认完全退出了旧进程，并使用新增代理图标启动。连接测试不代表账号资格或所有 AI 功能都正常。

**图标创建失败**：确认当前用户可以写入桌面和开始菜单。同名快捷方式不属于本工具时，会要求你先重命名，不会覆盖它。

**仍然出现设置窗口**：直接双击工具的 exe 默认打开设置；日常静默启动需要使用新建的代理图标。

## 移除

先退出启动组件的设置窗口，再删除本工具创建的桌面图标、开始菜单设置入口和上述 AppData 目录即可。不需要改动 Antigravity 安装目录。
